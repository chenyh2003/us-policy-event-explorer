# 美国政策事件交互网站 — 设计规格

- 日期：2026-11-05
- 项目目录：`C:\Users\cyh23\OneDrive\Desktop\美股\site`
- 状态：已获设计批准，待实现

## 1. 目标

把现有 `美股` 资料夹中的 108 条政策事件做成一个可部署的前端网站。用户可以：

1. 查看标普500曲线与 1912—2026 政策时间轴；
2. 选择展示哪些事件，也可以**逐个关闭**不想看的事件；
3. 按类别、结构层、年代、关键词、政策工具筛选；
4. 点击任意事件，查看比现有 CSV 更细的结构化解析。

默认打开时 **108 条全部开启**；任何一条都可以关闭，关闭后图表、时间轴、计数同步更新。

## 2. 非目标

- 不做后端、登录、数据库或实时行情。
- 不做投资建议、买卖信号或收益预测。
- 不在本期接入外部 API；数据全部本地打包。
- 不做 108 条以外的自动抓取。

## 3. 技术方案

- **Vite + React + TypeScript**
- **ECharts** 负责标普500曲线、事件散点、缩放与时间轴
- 纯前端静态数据，`npm run build` 产出 `dist/`
- 不依赖运行时服务；可部署到任意静态托管
- 采用手写 CSS（CSS Modules 或普通 CSS），不引入大型 UI 框架

## 4. 页面结构

### 4.1 顶部栏

- 标题：`美国政策事件与标普500`
- 副标题：数据口径、1927—2026 曲线、1912—2026 政策时间轴
- 快捷按钮：
  - `全部开启`
  - `全部关闭`
  - `反选`
  - `核心32`
  - `K1—K11`
- 已开启数量 / 总数（例如 `108 / 108`）

### 4.2 左侧筛选与事件列表

- 搜索框：事件名、机构、政策工具、关键词
- 类别筛选：价格、黄金、工资、宏观
- 结构层筛选：货币/黄金、价格/产业、劳动/工资、能源/资源、医疗/消费、宏观/制度
- 年代筛选：1912—1929、1930—1945、1946—1979、1980—2000、2001—2026
- 政策工具筛选：按工具标签多选
- 显示选项：`仅看已开启`
- 事件列表：
  - 每条显示日期、标题、类别、结构层、关键工具标签
  - 每条有独立开关
  - 点击标题/行打开详情，不改变开关状态
- 分组开关：
  - 类别、结构层、年代组支持三态（全开 / 部分 / 全关）
  - 点击组开关可一次开启/关闭该组全部事件

### 4.3 标普500主图

- 数据：1927-12-30 至 2026-06-03，24,722 个日收盘点；对数轴
- 只显示已开启且日期 >= 1927-01-01 的事件标记
- 标记颜色按类别：
  - 价格：橙色
  - 黄金：金色
  - 工资：绿色
  - 宏观：蓝色
- 标记可点击，点击打开详情
- 悬停显示：日期、事件名、类别、结构层、关键工具
- 支持缩放、拖拽、重置
- 1927 年前事件不强行放到曲线上；在下方时间轴展示并注明

### 4.4 政策时间轴

- 范围：1912—2026
- 6 条结构层轨道
- 已开启事件显示为点/短条；点击打开详情
- 用于承载 1927 年前事件，以及展示政策密度
- 与主图共享选择状态和类别颜色

### 4.5 事件详情

右侧抽屉（移动端为底部弹层），包含：

1. 标题、日期、类别、结构层
2. 一句话结论
3. 政策工具细分：工具标签 + 参数 + 具体做法
4. 作用对象、覆盖范围、豁免
5. 传导链：3—5 步
6. 关键数字：价格、税率、覆盖率、持续时间等
7. 市场影响：股票、利率、美元、黄金、行业
8. 执行机构、执行方式、退出方式
9. 副作用：短缺、黑市、排队、质量、投资扭曲等
10. 受益行业 / 受损行业
11. 关联事件（可跳转）
12. 来源章节
13. `关闭此节点` 按钮

## 5. 选择与状态

- 初始状态：108 条全部开启
- 单个事件开关独立生效
- 分组开关支持三态
- `全部开启` / `全部关闭` / `反选` 立即生效
- `核心32`：只开启标普图中的 32 个三类事件
- `K1—K11`：只开启 11 个关键标注事件
- 选择状态写入 `localStorage`，刷新后恢复
- 筛选条件不改变开关状态；`仅看已开启` 只影响列表显示
- URL 可选保存选择状态；本期不做强制要求

## 6. 数据模型

运行时数据放在 `public/data/`：

### `events.json`

```ts
interface PolicyEvent {
  id: number
  date: string
  endDate?: string
  category: '价格' | '黄金' | '工资' | '宏观'
  title: string
  policyType: string
  coverage: string
  summary: string
  layers: string[]              // 主结构层 + 次结构层
  instruments: InstrumentTag[]  // 细分工具
  targets: string[]
  exemptions: string[]
  transmission: string[]        // 3—5 步
  metrics: Metric[]
  marketImpact: {
    equities: string
    rates: string
    usd: string
    gold: string
    sectors: string
  }
  enforcement: string
  exit: string
  sideEffects: string[]
  winners: string[]
  losers: string[]
  relatedIds: number[]
  sources: string[]
  keyAnnotation?: string        // K1—K11
}
```

```ts
interface InstrumentTag {
  code: string
  label: string
  parameter: string   // 具体参数，如“旧油上限 5.25 美元/桶”
  detail: string      // 这条事件里具体怎么执行
}
```

### `spx.json`

- `[date, close]` 数组，24,722 条
- 构建时从 `../data/标普500_1927-2026.csv` 生成

### `taxonomy.json`

- 6 个结构层定义
- 约 30 个政策工具标签及解释
- 类别颜色、工具分组

## 7. 内容要求

108 条全部补齐结构化解析，不能只写“配额”“管制”这种概括词。

政策工具至少覆盖以下细分：

- 价格：最高限价/冻结、最低限价/担保价、双轨价、指导线、自愿协议、生产配额、进口配额、出口限制、配给券、许可证/审批、价格申报、补贴/税收抵免、政府采购/储备、租金管制、反囤积/反暴利
- 工资：工资冻结、工资上限、工资公式/COLA、工资委员会/仲裁、冷却期、最低工资、加班溢价、福利/社保、集体谈判、税收惩罚/激励
- 黄金：官价、国有化/强制上缴、兑换限制、出口许可/禁运、储备要求、双轨制、央行售金上限、黄金去货币化、私人持有禁止/合法化
- 宏观：战争动员、财政扩张、货币制度、贸易政策、监管制度

每条事件至少包含：

- 2 个以上工具标签（确实只有一个工具的除外）
- 具体参数或覆盖比例
- 3 步以上传导链
- 至少 1 个关键数字
- 至少 2 个副作用
- 受益/受损行业
- 来源章节

示例（EPAA 1973）：

- 工具：旧油/新油双轨价；旧油价格上限；炼厂配额；Entitlements 现金补贴；成本转嫁规则
- 参数：旧油上限约 5.25 美元/桶；新油不受上限约束
- 传导：旧油低价 → 炼厂争抢低价油 → 配额分配 → 成品油价格与炼化利润分化
- 副作用：短缺、进口依赖、炼厂投资扭曲、配额寻租

## 12. 已知约束

- 标普数据从 1927-12-30 开始；1912—1927 事件只能在政策时间轴展示。
- 标普数据截至 2026-06-03；2026-06-03 之后的事件（如 2026-09-18）只在政策时间轴展示，并标注“超出行情数据范围”。
- 现有 CSV 的“关键内容”是摘要，详细解析需要结合 `01/02/03/05/07` 报告逐条校对。
- 个别历史数字存在口径差异；详情中保留“口径/待核”标记，不把不确定数字写成确定事实。
- 网站是研究工具，不构成投资建议。
