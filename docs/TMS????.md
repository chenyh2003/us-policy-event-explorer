## 一、口径选择

本文采用 **Rothbard–Salerno 的 TMS2** 口径。

在奥地利学派内部，TMS 有多个版本：

- **TMS1**：较窄，通常不包括储蓄存款；
- **TMS2**：较宽，包括储蓄存款和 MMDA，但不包括小额定期存款、零售货币市场基金（retail MMF）和旅行支票；
- **M Prime**：另一套更窄的口径。

本文使用 TMS2，原因是我们关注的是“可随时按面值转换为一般交换媒介”的美元索取权；储蓄存款和 MMDA 在现实中具有很高的流动性，应与活期存款一起纳入。

## 二、1969 年后的计算公式

使用 FRED 月度、季调序列：

```text
TMS2 = M2SL - STDSL - RMFSL + TREASURY
```

### 2.1 公式的文字读法

一句话：**TMS2 = M2 里真正能按面值随时当货币用的部分，减去不能随时按面值变现的部分，再加回政府持有的货币。**

逐项读：

1. **从 M2 出发**。M2 是一个“广义流动性”篮子，里面既有现金、活期存款、其他支票存款、储蓄存款/MMDA，也有小额定期存款和零售货币市场基金。它把“能直接支付的钱”和“比较接近钱、但不能随时按面值支付的东西”放在了一起。
2. **减去小额定期存款（`STDSL`）**。小额定期存款有约定期限，提前支取通常要损失利息，不能像活期存款那样按面值随时支付；它不是 TMS 意义上的“一般交换媒介”，所以从篮子里拿掉。
3. **减去零售货币市场基金（`RMFSL`）**。零售 MMF 的份额价格可以浮动，赎回也可能有限制，不是按面值即期支付的存款索取权；它更接近“流动性资产”，不是“货币本身”，所以拿掉。
4. **加回财政部在美联储的存款（`TREASURY`）**。M2 主要统计私人部门持有的货币；但财政部在美联储的存款也是美元货币存量的一部分，只是持有者是政府。TMS 统计的是“所有经济主体持有的货币”，所以把这部分加回来。
5. **保留现金、活期存款、其他支票存款、储蓄存款/MMDA**。这些是 TMS2 的核心：它们要么是现金本身，要么是按面值即时可转换成现金、且在日常支付/清算中广泛接受的索取权。

所以，公式不是“随便加减”，而是在做一次**货币口径的重新分类**：

- 把 M2 中“不是即期面值货币”的定期存款和零售 MMF 剔除；
- 把 M2 中漏掉的政府货币持有加回；
- 剩下的就是 TMS2。

### 2.2 为什么不是直接看 M2

M2 的优点是连续、易得，但它的边界是“流动性”而不是“货币性”。TMS2 的边界更窄：只把能按面值即时充当交换媒介的索取权算作货币。两者在大多数时候同向变动，但在利率上行、存款脱媒、MMF 扩张或财政部现金余额大幅变化时，差异会变大。

### 2.3 一个算例

以 1969-01 为例（单位：十亿美元）：

```text
M2SL      = 569.3
STDSL     = 102.4
RMFSL     = 0.0   （该序列 1973 年才开始）
TREASURY  = 0.0   （该序列 1986 年才开始）

TMS2 = 569.3 - 102.4 - 0.0 + 0.0 = 466.9
```

也就是说，1969 年 1 月的 M2 中约有 102.4 十亿美元是小额定期存款；把这部分拿掉后，得到约 466.9 十亿美元的 TMS2。

### 2.4 常见误解

- **“TMS 就是 M2 加一项”**：不是。TMS 是重新定义货币边界，既有减法也有加法。
- **“储蓄存款不算货币”**：TMS2 认为储蓄存款/MMDA 可按面值即时转为支付手段，应计入；TMS1 则更窄，不计储蓄存款。
- **“零售 MMF 也是货币”**：TMS2 不纳入，因为份额价格浮动、非按面值即期支付。
- **“财政部存款不影响货币”**：从全社会货币存量看，它也是美元持有，只是持有者是政府，所以加回。

### 数据起点与缺失处理

- `M2SL`、`STDSL` 从 1959-01 开始；
- `RMFSL` 从 1973-01 开始，1973 年前按 0 处理；
- `TREASURY` 从 1986-01 开始，1986 年前按 0 处理；2025-10 之后没有新值，按 2025-10 的最后值延续；
- 本文 TMS2 从 **1969-01** 开始，这是常用 TMS 样本起点，也避开了 1959—1968 年部分组件不完整的问题。

## 三、1969 年前的 Friedman–Schwartz 代理

1969 年前没有与 TMS2 完全对应的月度组件序列。本文使用 Friedman & Schwartz《美国货币史》体系下的 **M2 月度序列**作为代理：

- NBER Macrohistory `m14144a`：1907-05 至 1946-12；
- NBER Macrohistory `m14144c`：1947-01 至 1969-09；
- 这两个序列的口径是：通货 + 商业银行活期存款 + 调整后的定期存款，季调，十亿美元；
- 本文取 1912-01 至 1968-12 的月度值。

### 比例拼接

### 1969 年前是直接数据，不是 TMS2 公式

1969 年以前没有按月发布的、与 TMS2 完全对应的组件序列。Friedman–Schwartz 提供的是 **M2 月度数据**，不是按“现金 + 活期 + 其他支票 + 储蓄/MMDA − 小额定期 − 零售 MMF + 财政部存款”逐项计算的 TMS2。

所以，1969 年前的处理是：

```text
直接使用 Friedman–Schwartz 月频 M2 数据
→ 再乘一个固定比例，把它平移到 1969 年 TMS2 的水平
```

不是：

```text
用 M2SL - STDSL - RMFSL + TREASURY 逐月计算
```

原因：

- 1969 年前没有月度 `STDSL` 与 `RMFSL` 的完整拆分；
- Friedman–Schwartz 的 M2 已经包含定期存款，但无法在月度频率上把“储蓄存款”和“小额定期存款”稳定分开；
- 因此只能用 M2 作为代理，再用比例拼接消除口径断点。

1968-12 的 Friedman M2 为 **399.7** 十亿美元；1969-01 的 TMS2 为 **466.9** 十亿美元。两者水平不同，主要来自口径差异，而不是真实货币存量在单月跳升 17%。

为避免在图上出现虚假断点，本文做**比例拼接**：

```text
ratio = TMS2(1969-01) / M2(1968-12)
      = 466.9 / 399.7
      ≈ 1.168126

TMS_spliced(t) = M2(t) × ratio,  t < 1969-01
```

这意味着：

- 1969 年前的**增速**仍来自 Friedman–Schwartz M2；
- 1969 年前的**水平**按 1969 年 TMS 水平缩放；
- 因此 1969 年前的水平不是原始 TMS 水平，而是“与 TMS 同尺度的 M2 代理”。

## 四、同比增速

月度同比按 12 个月滞后计算：

```text
YoY(t) = (TMS(t) / TMS(t-12) - 1) × 100%
```

1969 年前使用拼接后的 TMS；由于比例拼接是常数乘法，1969 年前的同比增速与原始 Friedman M2 完全一致。

## 九、限制

1. **1969 年前不是严格 TMS**：Friedman–Schwartz 没有提供与 TMS2 完全一致的月度组件拆分，M2 是代理。
2. **水平拼接不是原始数据**：1969 年前水平经过比例缩放，适合看趋势和增速，不适合当作原始 TMS 水平引用。
3. **TREASURY 覆盖不完整**：1986 年前按 0，2025-10 后按最后值延续；这会影响 TMS 的尾部水平。
4. **旅行支票省略**：金额小，且 FRED 序列停止维护。
5. **数据修订**：FRED 会修订历史 M2 组件；本文使用 2026-11 下载版本。
6. **TMS1/TMS2 争议**：若采用 TMS1，应剔除储蓄存款/MMDA，结果会明显更低。
7. **不是投资建议**：TMS 是货币度量，不构成交易信号。
